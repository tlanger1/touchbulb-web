TouchBulb BLE Controller - release notes
========================================
Upload index.html and release_notes.txt together to the same GitHub folder.
The version number is also shown at the bottom of the page, so you can see
whether the phone loaded the new file.

Version 1.4 - 2026-11-25
- New "Clear list" button in "Manage devices", next to "Connect all" and
  "Disconnect all". It asks for a second tap, then starts from scratch: it
  disconnects everything, forgets the saved boards, clears the page's memory of
  boards that connected before, and turns "Show all nearby devices" off.
- Bluefy cannot forget saved devices, so cleared boards are hidden on this page
  instead. A hidden board comes back when you pick it from the Bluetooth list.

Version 1.3 - 2026-11-25
- Fix for "Reconnect saved devices" failing after a page reload: after a reload
  the browser has not scanned yet, so saved boards cannot be connected directly.
  The page now listens for about 8 seconds for the boards advertising (where the
  browser allows it). Boards it hears are marked ready and light the yellow button.
- Boards it cannot connect directly are no longer offered as yellow/Connect/Retry.
  The yellow button stays grey, "Manage devices" shows a red dot, and a line under
  the board summary says how many boards need to be selected from the list.
- In "Manage devices" these boards have a "Pick from list" button (replaces
  "Retry"). It opens the Bluetooth list narrowed to that board, as "Connect a BLE
  device" does, and the board then works for direct reconnects in this session.
- "Connect all" now connects only the boards that can be connected directly and
  says how many others need "Pick from list".

Version 1.2 - 2026-11-25
- The "Manage devices" panel now opens at the top of the visible screen and is
  sized to what you can actually see, instead of hanging from the bottom edge
  (where part of it was hidden on iPhone SE). The board list scrolls inside it.
- In the Controls section the slider is now above "Operation mode".

Version 1.1 - 2026-11-25
- "Reconnect saved devices" (the yellow button) now counts and reconnects only
  boards that have connected successfully before. Boards that were only picked,
  or never connected, no longer light it up after a reload or fail when tapped.
- The page now remembers, on this phone only, which boards have connected and
  when. Forgetting a board in "Manage devices" also removes it from this memory.
- "Manage devices" shows "Never connected" or "Last connected ... ago" for each
  board, and the summary line counts never-connected boards separately.
- "Connect all" and each board's Connect button still try every board, so a
  first connection remains one tap.
- The page version is now shown at the bottom of the page.

Version 1.0 - the version that was online before this file existed
(no notes kept).
