Activity log and advanced settings 

      
    
        
  • A successful Bluetooth write does not prove the board's microcontroller received the text. Check the board's UART output or the LED.
    • 
        
  • You can tap "Connect another BLE device" again while a board is still connecting. The connections run in parallel.
    • 
        
  • "Reconnect saved devices" turns yellow when boards that have connected before are not connected but can be reconnected directly: they were used earlier in this page session, or the page has just heard them advertising. After a page reload the browser has not scanned yet, so the page first listens for a few seconds. Boards it cannot reach directly get a red dot on "Manage devices": open it and tap "Pick from list" for each board. A board that never connected is shown as "Never connected" and is connected the same way.
    • 
        
  • Nothing is sent over the internet. If you switch on "Remember boards on this phone" (in "Manage devices"), the page keeps, on this phone only, which boards have connected and when, and uses Bluefy's list of saved boards. The switch is off by default. Switched off, the page keeps boards only for this browser tab (in temporary storage that is cleared when the tab is closed), so they survive iOS restarting the page while Bluefy is in the background, and it deletes anything it stored earlier.
    • 
        
  • "Clear list" in "Manage devices" (two taps) starts from scratch: it disconnects everything, forgets the saved boards (or hides them on this page if the browser cannot forget them), clears the memory above and turns "Show all nearby devices" off. A hidden board comes back when you pick it from the Bluetooth list.
    • 
        
  • Leaving Bluefy or locking the phone breaks Bluetooth connections. On iPhone this page then closes them itself so the boards are freed. Come back and tap "Reconnect saved devices" or "Connect a BLE device". The screen is kept awake while connected, if the browser allows it.
    • 
        
  • Only one program can hold a connection to a board at a time. Close the Python app before connecting here.
