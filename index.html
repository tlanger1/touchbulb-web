Activity log and notes 

      
    
        
  • A successful Bluetooth write does not prove the board's microcontroller received the text. Check the board's UART output or the LED.
    • 
        
  • You can tap "Connect another BLE device" again while a board is still connecting. The connections run in parallel.
    • 
        
  • Leaving Bluefy or locking the phone breaks Bluetooth connections. On iPhone this page then closes them itself so the boards are freed. Come back and tap "Connect a BLE device" (or "Reconnect saved devices" if it is shown). The screen is kept awake while connected, if the browser allows it.
    • 
        
  • Only one program can hold a connection to a board at a time. Close the Python app before connecting here.
